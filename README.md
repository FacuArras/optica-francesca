# Óptica Francesca

Sitio web para **Óptica Francesca** — Córdoba, Argentina.

## Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3**
- **React Router 6**
- **Lucide React** (iconos)

## Páginas

| Ruta | Descripción |
|------|-------------|
| `/` | Landing page con hero, servicios y ubicación |
| `/turnos` | Reserva de turnos con calendario y formulario |
| `/admin` | Panel de gestión de turnos (protegido con contraseña) |

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
